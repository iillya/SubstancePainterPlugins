# SubstancePainter映射校准助手

这个工具可以自动检测使用画笔工具或者其他工具时鼠标是在2D窗口还是在3D窗口，根据不同的窗口自动设置画笔工具属性里的校准和间距大小设置，提升绘画体验<br>

使用方法：将 映射校准助手.py 放入C:\Users\用户名\Documents\Adobe\Adobe Substance 3D Painter\python\plugins下即可<br>
